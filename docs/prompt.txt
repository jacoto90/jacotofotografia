# JACOTO FOTOGRAFÍA — Complete Project Context

## Overview
Modern Laravel 13 + Flux UI rebuild of a legacy PHP photography portfolio site for Hostalia shared hosting (FTP only, no SSH). Public-facing gallery site + password-protected client photo books + admin panel with CRUD, photo upload, and email notifications.

## Tech Stack
- **Backend**: Laravel 13 (PHP 8.3), MySQL (prod), SQLite (local)
- **Frontend**: Flux UI v2 (Tailwind-based components), Vite
- **Auth**: Laravel built-in Auth (session-based)
- **Storage**: Filesystem (local `storage/app/public`), symlinked via `public/storage`
- **Deployment**: FTP upload (no SSH available), `.env` excluded from deploy, manual upload

## Routes
- `/` — Homepage
- `/clientes` — Guest gallery (book cards with password modal)
- `/book/access` — POST: validate password, show book photos
- `/book/download` — POST: create ZIP of selected photos
- `/contacto` — Contact page
- `/jacoto` — Personal/Jacoto page
- `/admin/login` — Admin login (throttled: 5/60min)
- `/admin/` — Dashboard (auth)
- `/admin/books/*` — CRUD + photo management
- `/admin/clientes/*` — CRUD
- `/admin/mensajes` — Messages from visitantes table
- `/admin/settings` — SMTP + notification config

## Covers
- FTP books: `public/{nombrebook}/foto_portada.jpg`
- Uploaded books: `storage/app/public/books/{id}/foto_portada.jpg`
- Cache busting: `?v={{ filemtime(...) }}`
- Setting cover: POST `/admin/books/{id}/photos/cover` with `photo` and `source` fields

## Key Decisions
- **No @fluxAppearance**: Force light mode via localStorage + JS, CSS :root{color-scheme:light}
- **No Variant="ghost"**: All admin buttons replaced with explicit HTML + inline styles
- **Data migration**: SQLite → MySQL via PHP script with hardcoded INSERTs
- **Photo paths**: FTP photos in public/{nombrebook}/ (not resources/oldweb/)
- **Mail config**: DB settings table (not .env) so admin can configure via UI

## Known Issues
- Artisan migrate fails on Hostalia (table already exists) — use manual schema scripts
- FTP directory names with accented chars get corrupted by PowerShell — use PHP or rename without accents
- Browser caching of cover images — solved with ?v=filemtime()

## Deployment
1. `npm run build` locally
2. Zip project (exclude .env, vendor, node_modules, storage)
3. Upload via FTP to site root
4. Extract via deploy.php or manual PHP unzip
5. Upload .env separately
6. Upload public/build/ separately
7. Ensure public/storage symlink exists
